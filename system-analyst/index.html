Postman Collection & Test Guide

File koleksi Postman v2.1 resmi untuk profile System Analyst telah disiapkan di folder ini:

Daftar Request dalam Postman Collection & Fungsinya:

Folder Nama Request Method Endpoint & Parameter Fungsi & Kegunaan Utama
OpenAI Compatible (/v1) 1. Health Check - List Models GET /v1/models Memeriksa kesehatan server gateway SA (Port 8643) & memastikan model system-analyst aktif.
2. Chat Completion (Stateless) POST /v1/chat/completions
Body: messages[]		 Mengirim prompt skenario SA tanpa simpan sesi. Cocok untuk pembuatan cepat outline TSD, DDL snippet, atau Event envelope.
Native Sessions (/api/sessions) 1. Create New Session POST /api/sessions
Body: {"title": "..."}		 Membuat sesi perancangan TSD/proyek baru di SQLite server. Mengembalikan session_id unik.
2. Send Chat to Session (Stateful) POST /api/sessions/:session_id/chat
Body: {"message": "..."}		 Mengirim instruksi lanjutan (seperti "Buatkan DDL Flyway", "Tambahkan audit trail") secara interaktif berkesinambungan.
3. Get Session Messages History GET /api/sessions/:session_id/messages Mengambil seluruh rekam jejak riwayat perancangan TSD/DDL yang pernah dihasilkan pada sesi tersebut.
4. Delete Session DELETE /api/sessions/:session_id Menghapus sesi perancangan TSD yang sudah selesai atau tidak digunakan lagi dari database server.

Cara Import & Menggunakan di Postman:

  1. Download file JSON di atas atau copy isi skema JSON di bawah ini.
  2. Buka Postman ➡️ Klik tombol Import (kiri atas).
  3. Drag & Drop file JSON atau Paste teks skema.
  4. Variabel {{baseUrl}} (http://203.145.34.37:8643) dan {{apiKey}} sudah terkonfigurasi secara otomatis.
  5. Jalankan request 1. Health Check lalu coba Create New Session & Send Chat to Session.
