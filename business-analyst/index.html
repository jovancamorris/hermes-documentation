Cakupan & Peran Agen Business Analyst

Profile business-analyst bertugas menerjemahkan kebutuhan bisnis pengguna menjadi spesifikasi fungsional yang terstruktur:

  • Menulis & Review BRD / FSD — Menyusun bab kebutuhan bisnis dan analisis fungsional.
  • User Story & Acceptance Criteria — Format "As a [user], I want [feature] so that [benefit]".
  • Business Process Flow — Menyusun diagram alur bisnis & matriks persetujuan (Approval Matrix).
  • Use Case Catalog — Menyusun skenario use case utama dan skenario alternatif.

Daftar Request dalam Postman Collection, Fungsi, & Skenario Penggunaannya:

Folder Nama Request Method Endpoint & Parameter Fungsi & Kegunaan Utama Skenario Penggunaan (Real-World)
OpenAI Compatible (/v1) 1. Health Check - List Models GET /v1/models Memeriksa kesehatan server gateway BA (Port 8642) & memastikan model business-analyst aktif. Smoke test konektivitas server gateway sebelum pengujian otomatis di pipeline CI/CD atau sebelum integrasi API ke frontend.
2. Chat Completion (Stateless) POST /v1/chat/completions
Body: messages[]		 Mengirim prompt skenario BA tanpa simpan sesi (stateless). Respon langsung dikembalikan tanpa riwayat database. Tanya-jawab instan seputar standar FSD/BRD EKSAD, draf singkat 1 User Story tunggal, atau verifikasi istilah bisnis cepat.
Native Sessions (/api/sessions) 1. Create New Session POST /api/sessions
Body: {"title": "..."}		 Starter chat yang mana nanti akan disimpan di SQLite server (hermes own). Mengembalikan session_id unik dari chat tersebut. Inisialisasi percakapan perancangan BRD/FSD proyek baru (contoh: "Procurement Approval Matrix") agar memiliki konteks yang bertahan lama.
2. Send Chat to Session (Stateful) POST /api/sessions/:session_id/chat
Body: {"message": "..."}		 Mengirim instruksi analisis lanjutan secara interaktif berkesinambungan dengan konteks percakapan yang terus diingat agen BA. Penyusunan BRD multi-tahap (misal: "Buat daftar User Story" ➡️ "Tambahkan Acceptance Criteria tiap story" ➡️ "Susun Approval Matrix").
3. Get Session Messages History GET /api/sessions/:session_id/messages Mengambil seluruh rekam jejak riwayat analisis kebutuhan bisnis yang pernah dihasilkan pada session_id tersebut. Memuat ulang riwayat percakapan BRD pada UI portal pengguna atau melakukan audit trail terhadap dokumen kebutuhan bisnis yang dibuat.
4. Delete Session DELETE /api/sessions/:session_id Menghapus data sesi beserta seluruh riwayat percakapannya dari database SQLite server (hermes own). Membersihkan sesi analisis yang sudah selesai di-export ke BRD/FSD final, atau menghapus percakapan uji coba yang tidak lagi digunakan.

Cara Import & Menggunakan di Postman:

  1. Download file JSON di atas atau copy isi skema JSON di bawah ini.
  2. Buka Postman ➡️ Klik tombol Import (kiri atas).
  3. Drag & Drop file JSON atau Paste teks skema.
  4. Variabel {{baseUrl}} (http://203.145.34.37:8642) dan {{apiKey}} sudah terkonfigurasi secara otomatis.
  5. Jalankan request 1. Health Check lalu coba Create New Session & Send Chat to Session.
